Getting started

Three steps to see your deploys here:

  1. 1 · Register your project

    Open Projects and add each GCP project whose deploys you want to watch. Every project must have a service account that the portal uses to list its deploys.

    Roles & permissions: the portal's own service account needs the Service Account Token Creator role (roles/iam.serviceAccountTokenCreator) on the project's service account, and that service account needs read access to the listing APIs (App Engine Viewer / Cloud Run Viewer).

  2. 2 · Configure the collector

    Add the deploy-info-collector Gradle plugin to the project's build.gradle.kts and run deployInfoCollect after every deploy:

    @for (line of snippetLines; track line.n) {{{ line.n }}{{ line.text || ' ' }}}

  3. 3 · You're done

    All deploys collected after that will show up here in Deploys.
