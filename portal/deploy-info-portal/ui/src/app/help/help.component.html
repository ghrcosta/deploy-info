Three steps to see your deployments here:

  1. 1 · Register your project

    Open Projects and add each GCP project whose deployments you want to watch. Every project must have a service account that the portal uses to list its deployments.

    Roles & permissions: the portal's own service account needs the Service Account Token Creator role (roles/iam.serviceAccountTokenCreator) on the project's service account, and that service account needs read access to the listing APIs (App Engine Viewer / Cloud Run Viewer).

  2. 2 · Configure the collector

    Add the deploy-info-collector Gradle plugin to the project's build.gradle.kts and run deployInfoCollect after every deployment:

    @for (line of snippetLines; track line.n) {{{ line.n }}{{ line.text || ' ' }}}

    Not building with Gradle? Call the standalone Python collector (deploy_info_collector.py from the deploy-info repository) instead, after every deployment — it needs Python ≥ 3.10, git, and an authenticated gcloud CLI:

    @for (line of pythonCliSnippetLines; track line.n) {{{ line.n }}{{ line.text || ' ' }}}

    Or call it from another Python script (e.g. CI tooling):

    @for (line of pythonScriptSnippetLines; track line.n) {{{ line.n }}{{ line.text || ' ' }}}

  3. 3 · You're done

    All deployments collected after that will show up here in Deployments.
