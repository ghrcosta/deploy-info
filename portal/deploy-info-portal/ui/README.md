# Ui

The Angular frontend (Angular CLI, version 22.2).

## Requirements

- Node.js **24.x** (tracked in `.nvmrc`; with [nvm](https://github.com/nvm-sh/nvm) installed, run
  `nvm use` inside this directory).
- TypeScript ~6.0.x is managed by the Angular tooling in `package.json`.

## Development server

Run `ng serve` and open `http://localhost:4200/`. The application automatically reloads whenever you
modify any of the source files.

## Building

Run `ng build`; the production build artifacts land in `dist/`.

## Running unit tests

Run `ng test` (always headless — see the portal's [running-locally documentation](../documentation/development/running-locally.md)
for the headless setup).

## Additional resources

For detailed command references, visit the [Angular CLI Overview and Command
Reference](https://angular.dev/tools/cli) page.
